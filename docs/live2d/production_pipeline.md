# 制作流程与验收标准

## A. PSD 美术制作
1. 先确定正面比例图：头部约占整体高度 42–48%，身体圆润、短腿，尾巴向画面左侧或右侧自然弯曲。
2. 所有可动区域独立图层；保留透明背景，不要把投影、白色画布合并进角色。
3. 眼睛、眉眼/眼睑、瞳孔、高光需独立绘制。墨镜默认覆盖眼睛，但不能与眼睛合并。
4. 墨镜上推时，需要额头毛色/纹理的补绘层；镜框、镜片、高光、鼻梁连接和镜腿尽可能分开。
5. 左右耳、左右前爪、尾巴、项圈和铃铛分别独立。
6. 为头部转动补足侧面遮挡下的脸颊、耳根、脖子区域；避免转动时出现透明缺口。
7. 图层名称使用 CSV 清单中的英文 ID 或团队约定名称，确保导入 Cubism 后容易定位。

## B. Cubism 建模与绑定
1. 导入分层 PSD，检查 ArtMesh 透明边缘与图层顺序。
2. 创建 Warp Deformer：Head、Face、Ear_L/R、Body、Tail、Paw_L/R、Sunglasses、Collar、Bell。
3. 先绑定 ParamAngleX/Y/Z，再处理眼睛、嘴型和墨镜推起。
4. 露眼动作建议使用 `ParamGlassesUp`（0=佩戴，1=推至额头）；眼睛参数独立控制，不能仅用单张替换贴图冒充完整眼睛系统。
5. 物理设置先小幅度：耳朵轻摆、尾巴延迟、铃铛摆动、胸腹呼吸。避免高频抖动。
6. 创建至少一个待机循环和一个墨镜上推动作；可选点击反馈、开心、困倦等动作。
7. 导出 moc3、model3.json、纹理图集、physics3.json 和 motions（如有）。

## C. 网站验收
- 模型透明背景，无白色矩形底板。
- 桌面端固定在右下角；不会挡住主要按钮，可配置关闭/隐藏。
- 页面缩放和窗口改变时保持正确锚定。
- 鼠标悬停或点击有响应；键盘焦点和减少动态效果偏好有合理处理。
- 缺少模型文件时显示友好占位，不应让整个页面报错。
- 在目标浏览器中测试内存、加载时间和长时间待机性能。

## D. 必须由实际模型验证的事项
- 头部左右转动是否有足够侧面补绘。
- 墨镜推起时是否出现额头空洞、镜腿穿模或眼睛错位。
- 眼睛是否能自然眨动、左右眼是否可独立控制。
- 物理效果是否在低帧率下稳定。
